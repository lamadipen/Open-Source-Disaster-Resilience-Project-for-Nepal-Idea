# Contributing to Nepal Disaster Resilience

Thank you for your interest in helping Nepal become more resilient to disasters!

## How to Submit an Idea

1. Go to the **Issues** tab.
2. Click **New Issue**.
3. Choose the **Idea Submission** form.
4. Fill out the required fields and submit.

Your idea will automatically appear on our [Idea Pipeline board](#).

## How the Pipeline Works

- **Submitted**: Your idea has been received.
- **Under Review**: Mentors are evaluating the feasibility and impact.
- **Selected**: The idea is approved for development.
- **In Development**: A team is actively building the solution.
- **Merged/Shipped**: The feature is complete and integrated into the main track.

## Coding Standards

- Follow the existing project structure: `/data`, `/models`, `/app`.
- Write clean, documented code.
- Ensure all PRs include tests.
- Use descriptive commit messages.

## Getting Help

If you have questions, please use the [GitHub Discussions](https://github.com/your-org/your-repo/discussions) section.
